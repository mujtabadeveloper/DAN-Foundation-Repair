# DAN Foundation Repair

Responsive static website with animations and a project gallery.

## Use
Unzip, then upload index.html and the assets folder to the root of your GitHub repository.

## Deploy
- GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).
- Vercel: Import your repository, select Other, and leave the build command empty.

No installation or build step is required. The contact form opens the visitor's email application with a prepared message.
